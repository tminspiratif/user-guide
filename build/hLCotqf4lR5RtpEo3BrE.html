Dapatkan API Key

Langkah pertama yang wajib dilakukan sebelum melakukan integrasi kode adalah mendapatkan kredensial akses.
 
Setiap aplikasi yang ingin menggunakan microservice ini harus memiliki API Key yang unik. API Key ini berfungsi sebagai identitas aplikasi Anda dan digunakan untuk memvalidasi setiap permintaan transaksi.
  1. 1
    Cara Mendapatkan API Key
    Silakan hubungi administrator sistem melalui email: affan.one@gmail.com.
  2. 2
    Data yang Perlu Disiapkan
    Saat menghubungi administrator, pastikan Anda melampirkan:
    Nama Aplikasi.
    Domain/Origin aplikasi (misal: https://toko-anda.com atau http://localhost:4200 untuk tahap testing).
    Prefix ID yang diinginkan (misal: MUMI, HOUSE, APP).

Inisialisasi SDK

SDK ini menggunakan objek konfigurasi tunggal saat inisialisasi dan metode pendukung untuk menyusun data transaksi. Berikut adalah rincian parameter yang tersedia:

1. Constructor Parameter (PaymentConfig)

Saat memanggil new PaymentMicro({ ... }), Anda dapat mengirimkan objek dengan properti berikut:
ParameterTipedataDefaultDeskripsi
apiKeyStringWajibKunci akses unik aplikasi Anda. Hubungi affan.one@gmail.com untuk mendapatkan key ini.
customerObjectWajibObjek yang berisi informasi pembayar (Lihat detail di bawah).
methodStringOpsionalKategori pembayaran: credit_card, bank_transfer, wallet, cstore, direct_debit.
bankStringOpsionalProvider spesifik (Contoh: bca, gopay, alfamart). Jika tidak diisi, user akan melihat semua pilihan dalam kategori method.
detailArrayOpsionalDaftar item awal (opsional, bisa ditambah via addDetail).

2. Objek customer (Detail Pelanggan)

Informasi pembayar diperlukan untuk verifikasi dan pengiriman resi pembayaran.
ParameterTipedataDefaultDeskripsi
emailStringWajibAlamat email pelanggan yang valid.
first_nameStringOpsionalNama depan pembayar.
phoneStringOpsionalNomor telepon aktif pelanggan.

3. Metode addDetail(item)

Metode ini digunakan untuk menyusun keranjang belanja. Penting: Total nominal transaksi dihitung secara otomatis oleh server berdasarkan data ini untuk mencegah manipulasi harga di sisi client.
ParameterTipedataDefaultDeskripsi
nameStringWajibNama produk atau layanan (Maks. 50 karakter).
priceNumberWajibHarga satuan produk (Gunakan angka tanpa titik/koma).
quantityNumberWajibJumlah item yang dibeli.

4. Tabel Keterkaitan method & bank

SDK memiliki fitur Auto-Correction. Jika Anda memasukkan kombinasi yang tidak valid, SDK akan otomatis mereset bank menjadi null agar sistem tetap menampilkan pilihan pembayaran yang tersedia di kategori tersebut.
Kategori (method)Provider (bank) yang Valid
bank_transferbca, bni, bri, mandiri, permata, cimb
walletgopay, shopeepay, dana, qris, linkaja
cstorealfamart, indomaret
direct_debitklikbca, bca_klikpay
credit_card(Biarkan kosong, form kartu akan muncul otomatis)

5. Format Respon .pay()

Setelah memanggil fungsi .pay(), Anda akan menerima objek respon dengan struktur sebagai berikut:
  • Jika Sukses (success: true):
    • orderId: ID transaksi unik dengan prefix aplikasi Anda (Contoh: MUMI-170423...).
    • token: Snap token untuk integrasi frontend.
    • redirectUrl: URL halaman pembayaran (Gunakan window.location.href untuk mengarahkan user).
  • Jika Gagal (success: false):
    • error: Pesan kesalahan yang jelas (Contoh: Domain Restricted atau Unauthorized).
    • code: Kode status HTTP dari server.
💡 Info
Catatan Keamanan Penting:
Strict Pricing: Jangan mencoba mengirimkan total harga manual. Server hanya akan memproses total berdasarkan kalkulasi price * quantity dari tiap item di detail.
Domain Matching: Pastikan domain tempat SDK ini dijalankan sudah terdaftar di sistem kami, jika tidak, Anda akan menerima error Domain Restricted.
