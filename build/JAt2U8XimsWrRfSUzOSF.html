Map Snapshot

Mengubah satu QuerySnapshot (hasil getDocs atau onSnapshot) menjadi Array Object yang sudah menyertakan id

1. mapSnapshotToRows (Untuk List/Array)

Kegunaan: Mengubah satu QuerySnapshot (hasil getDocs atau onSnapshot) menjadi Array Object yang sudah menyertakan id.
// snapshots adalah QuerySnapshot[] (koleksi laci-laci halaman)
FirestoreService.mapSnapshotToRows(snap)

2. mapDocumentToObject (Untuk Single Data)

Kegunaan: Mengubah satu DocumentSnapshot (hasil getDoc) menjadi satu object tunggal.
getDetail(id: string) {
  getDoc(docRef).then(snapshot => {
    const cleanData = FirestoreService.mapDocumentToObject(snapshot);
    console.log(cleanData); // Output: { id: '123', name: 'John', ... }
  });
}

3. mapSnapshotToRowsFirst & Last

Kegunaan: Mengambil data paling pertama atau paling terakhir dari sebuah list hasil query secara aman.
const firstUser = FirestoreService.mapSnapshotToRowsFirst(querySnapshot);
const lastUser = FirestoreService.mapSnapshotToRowsLast(querySnapshot);

4. retrieveReference (Fitur Advanced/Relasi)

Kegunaan: Menarik data secara otomatis jika ada field yang tipenya DocumentReference (Relasi antar tabel).
Cara Pakai: Misal lo punya data Artikel yang punya field author (isinya link ke tabel User).
async loadArticleWithAuthor() {
  const snapshots = await getDocs(myQuery);
  const rawData = snapshots.docs.map(d => ({ id: d.id, ...d.data() }));

  // 'retrieveReference' bakal nge-scan dan narik data author secara otomatis
  const completeData = await FirestoreService.retrieveReference(rawData);
  this.items = completeData;
}

Parameter Interface

Kumpulan Interface Pendukung data Firestore Service

export interface COLLECTION_INTERFACE {
  collect: string;
  where?: (
    | QueryFieldFilterConstraint
    | QueryOrderByConstraint
    | QueryLimitConstraint
    | QueryStartAtConstraint
  )[];
  orderBy?: QueryOrderByConstraint[];
  limit?: QueryLimitConstraint;
  startAfter?: QueryStartAtConstraint;
}

export interface SCROLLER_CONFIG extends COLLECTION_INTERFACE {
  pageSize: number;
  scrollElement?: HTMLElement; // Jika null, maka pakai window
  nextPage$?: Observable<void>;
}

Ambil Dengan Paging

Mengambil koleksi secara realtime dengan dukungan Infinite Scroll

Cara pakai di Component

Standar pemakaian

const option = {
    collect: 'articles',
    pageSize: 20, // Jumlah data yang akan di load per page
}
  
this.service.getWithScroller(option).subscribe(res => {
    this.articles = res;
});

Menggunakan Next page secara manual

// Di Component.ts
manualNext$ = new Subject<void>();

const option = {
    collect: 'articles',
    pageSize: 2, // Misal datanya dikit
    nextPage$: this.manualNext$.asObservable() // Kirim manual trigger-nya
}

// Fungsi yang dipanggil saat tombol diklik
loadMoreManual() {
  this.manualNext$.next();
}

Parameter

getWithScroller(config: SCROLLER_CONFIG): Observable<any[]>
