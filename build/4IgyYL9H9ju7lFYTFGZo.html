Login Service

Layanan login API IAIN Madura

Untuk dapat menggunakan layanan service Login menggunaka API IAIN Madura

1. Import librari script dengan cara sebagai berikut, YOUR_API_KEY diperoleh dari TIPD

<script src="https://api.uinmadura.ac.id/assets/js/auth.js?v=0.2&key=YOUR_API_KEY"></script>

2. Implementasikan pada kode javascript seperti dibawah ini

const api = new AuthIAINMadura();
api.auth().then((response) => {
      //response adalah hasil setelah login sukses
});

3. Untuk menentukan default opsi yang ada pada service login, lakukan dengan cara sebagai berikut

const api = new AuthIAINMadura();
api.remember = true; //remember akan menyimpan supaya tidak perlu login lagi
api.logout = true; //akan memaksa keluar dari perangkat lain

4. Ada 3 cara untuk menerapkan login API Service IAIN Madura

const api = new AuthIAINMadura();
api.remember = true; //remember akan menyimpan supaya tidak perlu login lagi
api.logout = true; //akan memaksa keluar dari perangkat lain
1. menggunakan Service Login Form
api.auth().then((response) => {
      //response adalah hasil setelah login sukses
});
2. menggunakan Service Login Non Form
api.login(USERNAME, PASSWORD, LOGOUT).then((response) => {
      //response adalah hasil setelah login sukses
});
3. menggunakan ajax jQuery
$.ajax({
    type: 'POST',
    url: "https://api.uinmadura.ac.id/api/auth",
    headers: {
        "Auth-api-key": YOUR_API_KEY // api key yang diperoleh dari TIPD
    },
    data : {
        username: USERNAME, // username pengguna
        password: PASSWORD, // password pengguna
        logout: 1 // memaksa keluar dari aplikasi yang lain, defaultnya 0
    },
    dataType: "json",
    success: function(response) {
        // response berupa informasi token login
    }
});

5. Seletah result diperoleh, sebuah respon berupa JSON sebagai berikut:

{
  "ip": [string],
  "created_at": [string],
  "expires_at": [string],
  "token": [string],
  "user": {
    "email": [string | null],
    "level": [1 | 2], // 1 dosen karyawan, 2 mahasiswa
    "kode": [string],
    "aplikasi": [array name aplication],
    "profil": {
      "avatar": [string | null],
      "nama": [string],
      "alamat": [string | null],
      "telepon": [string | null]
    }
  }
}

6. Anda bisa mengecek token tersebut, untuk mengetahui atas kepemilikan user siapa, berikut caranya

// REST API menggunakan AJAX jQuery
$.ajax({
    url: "https://api.uinmadura.ac.id/api/auth/token",
    headers: {
        "Auth-token": YOUR_TOKEN,
        "Auth-api-key": YOUR_API_KEY
    },
    dataType: "json",
    success: function(response) {
        // response berupa informasi kepemilikan token tersebut
    }
});


// atau langsung embed dengan parameter URL
https://api.iainmadura.ac.id/api/auth/token?token=YOUR_TOKEN&key=YOUR_API_KEY
responnya berupa JSON
{
  "ip": [string],
  "created_at": [string],
  "expires_at": [string],
  "token": [string],
  "user": {
    "email": [string | null],
    "level": [1 | 2], // 1 dosen karyawan, 2 mahasiswa
    "kode": [string],
    "aplikasi": [array name aplication],
    "profil": {
      "avatar": [string | null],
      "nama": [string],
      "alamat": [string | null],
      "telepon": [string | null]
    }
  }
}

7. Untuk menghapus / menonaktifkan token, silahkan lakukan logout dengan cara sebagai berikut

// REST API menggunakan AJAX jQuery
$.ajax({
    url: "https://api.uinmadura.ac.id/api/auth/logout",
    headers: {
        "Auth-token": YOUR_TOKEN,
        "Auth-api-key": YOUR_API_KEY
    },
    dataType: "json",
    success: function(response) {
        // response berupa informasi kepemilikan token tersebut
    }
});

// atau langsung embed dengan parameter URL
"https://api.uinmadura.ac.id/api/auth/logout?token=YOUR_TOKEN&key=YOUR_API_KEY"

SSO Satè

Mengintegrasikan dengan login sate, pengecekan token autentikasi

Trigger Login via SSO Satè

  1. 1
    Dapatkan Token
    Pastikan token diperoleh melalui mekanisme Service Token
  2. 2
    Deteksi aktivitas token
    Tujuan mendeteksi atau mentrigger token agar tetap aktif selama tidak di logout,
💡 Info
Token akan expires otomatis dalam waktu 2 jam selama tidak ada trigger ke server

Endpoint untuk trigger token

https://api.uinmadura.ac.id/api/onhand/detect?key=[TOKEN]

[TOKEN]stringNoWajib diisi

Pegawai

Data pegawai UIN Madura

Mendapatkan data Pegawai UIN MADURA

Silahkan akses endopint dibawah ini dengan method GET
https://api.uinmadura.ac.id/api/pegawai

Parameter Pegawai

Nama paramTipedataDefaultDeskripsi
limitnumber30Jumlah data yang diambil
pagenumber1Posisi paging yang akan diambil
qistring|nullnullmencari berdasarkan kata kunci dengan kasus tidak sensitif
qstring|nullnullmencari berdasarkan kata kunci dengan kasus sensitif (harus sama)
kodestring|nullnullmencari berdasarkan kode pegawai spesifik
nipstring|nullnullmencari berdasarkan NIP
nidnstring|nullnullmencari berdasarkan NIDN
jenisstring|nullnullStatus yang tersedia, bisa PNS/PPPK dan lainnya
dosen1|0|nullnullmencari berdasarkan sebagai dosen atau tidak atau umum
satkerstring|nullnullmecari berdasarkan kode satker
homebasestring|nullnullmencari berdasarkan kode unit
golonganstring|nullnullmencari berdasarkan nama kelas atau pangkat
jafungstring|nullnullmencari berdasarkan nama jabatan fungsional
Cara penggunaan parameter:
Anda Dapatmenyertakan parameter ke url
https://api.uinmadura.ac.id/api/pegawai?page=1&limit=10
Misalnya ingin mencari Jhon maka cukup dengan cara
https://api.uinmadura.ac.id/api/pegawai?q=jhon, maka yang akan tampil yang cocok dengan kata jhon
✅ Tips
Jika ingin mencari dengan 2 atau lebih kata kunci yang berbeda, anda Dapatmenggunakan dengan cara 
https://api.uinmadura.ac.id/api/pegawai?group_{qi/q/id}={pisah dengan ","}
 
Contoh:
https://api.uinmadura.ac.id/api/pegawai?group_qi=jhon,smith maka data akan diperoleh yang cocok dengan jhon atau smith

Ringkasan URL Pegawai

  1. Dapatmembatasi limit data yang akan ditampilkan, limit defaultnya 30
    https://api.uinmadura.ac.id/api/pegawai?limit=[ANGKA]
  2. Menampilkan data berdasarkan page tertentu, defaultnya page ke 1
    https://api.uinmadura.ac.id/api/pegawai?page=[ANGKA]
  3. Dapatmenggunakan pencarian berdasarkan NAMA PEGAWAI (mode like)
    https://api.uinmadura.ac.id/api/pegawai?qi=[NAMA PEGAWAI]
  4. Dapatmenggunakan pencarian berdasarkan NAMA PEGAWAI
    https://api.uinmadura.ac.id/api/pegawai?q=[NAMA PEGAWAI]
  5. Dapatmenggunakan pencarian berdasarkan KODE USER
    https://api.uinmadura.ac.id/api/pegawai?kode=[KODE USER]
  6. Dapatmenggunakan pencarian berdasarkan SEBAGAI DOSEN
    https://api.uinmadura.ac.id/api/pegawai?dosen=[1/0]
  7. Dapatmenggunakan pencarian berdasarkan NIP PEGAWAI
    https://api.uinmadura.ac.id/api/pegawai?nip=[NIP PEGAWAI]
  8. Dapatmenggunakan pencarian berdasarkan NIDN PEGAWAI
    https://api.uinmadura.ac.id/api/pegawai?nidn=[NIDN PEGAWAI]
  9. Dapatdikelompokkan berdasarkan NAMA JENIS PEGAWAI
    https://api.uinmadura.ac.id/api/pegawai?jenis=[NAMA JENIS]
  10. Dapatmenggunakan pencarian berdasarkan Sakter
    https://api.uinmadura.ac.id/api/pegawai?homebase=[KODE SATKER]
  11. Dapatmenggunakan pencarian berdasarkan Homebase
    https://api.uinmadura.ac.id/api/pegawai?golongan=[KODE UNIT]
  12. Dapat menggunakan pencarian berdasarkan Jafung
    https://api.uinmadura.ac.id/api/pegawai?jafung=[NAMA JABATAN]
  13. Dapatmenggunakan pencarian berdasarkan Golongan
    https://api.uinmadura.ac.id/api/pegawai?satker=[NAMA KELAS, ATAU PANGKAT]
  14. Dapat menggunakan pencarian dengan multi kata kunci (OR)
    https://api.uinmadura.ac.id/api/pegawai?group_{kode/nip/nidn/qi/q/prod/fak/jenis}={pisah dengan ","}
  15. Atau beberapa parameter sekaligus
    https://api.uinmadura.ac.id/api/pegawai?qi=[NAMA PEGAWAI]&q=[NAMA PEGAWAI]&kode=[KODE USER]&nip=[NIP PEGAWAI]&nidn=[NIDN PEGAWAI]&prod=[ID PRODI]&fak=[ID FAKULTAS]&jenis=[NAMA JENIS]&group_{kode/nip/nidn/qi/q/prod/fak/jenis}={pisah dengan ","}&page=[ANGKA]&limit=[ANGKA]
⚠️ Warning
Untuk data dibawah ini dapat terisi null jika tidak tersedia 
1. Dosen
2. Satker
3. Jafung
