Layanan login API IAIN Madura

Untuk dapat menggunakan layanan service Login menggunaka API IAIN Madura

1. Import librari script dengan cara sebagai berikut, YOUR_API_KEY diperoleh dari TIPD

<script src="https://api.uinmadura.ac.id/assets/js/auth.js?v=0.2&key=YOUR_API_KEY"></script>

2. Implementasikan pada kode javascript seperti dibawah ini

const api = new AuthIAINMadura();
api.auth().then((response) => {
      //response adalah hasil setelah login sukses
});

3. Untuk menentukan default opsi yang ada pada service login, lakukan dengan cara sebagai berikut

const api = new AuthIAINMadura();
api.remember = true; //remember akan menyimpan supaya tidak perlu login lagi
api.logout = true; //akan memaksa keluar dari perangkat lain

4. Ada 3 cara untuk menerapkan login API Service IAIN Madura

const api = new AuthIAINMadura();
api.remember = true; //remember akan menyimpan supaya tidak perlu login lagi
api.logout = true; //akan memaksa keluar dari perangkat lain

1. menggunakan Service Login Form

api.auth().then((response) => {
      //response adalah hasil setelah login sukses
});

2. menggunakan Service Login Non Form

api.login(USERNAME, PASSWORD, LOGOUT).then((response) => {
      //response adalah hasil setelah login sukses
});

3. menggunakan ajax jQuery

$.ajax({
    type: 'POST',
    url: "https://api.uinmadura.ac.id/api/auth",
    headers: {
        "Auth-api-key": YOUR_API_KEY // api key yang diperoleh dari TIPD
    },
    data : {
        username: USERNAME, // username pengguna
        password: PASSWORD, // password pengguna
        logout: 1 // memaksa keluar dari aplikasi yang lain, defaultnya 0
    },
    dataType: "json",
    success: function(response) {
        // response berupa informasi token login
    }
});

5. Seletah result diperoleh, sebuah respon berupa JSON sebagai berikut:

{
  "ip": [string],
  "created_at": [string],
  "expires_at": [string],
  "token": [string],
  "user": {
    "email": [string | null],
    "level": [1 | 2], // 1 dosen karyawan, 2 mahasiswa
    "kode": [string],
    "aplikasi": [array name aplication],
    "profil": {
      "avatar": [string | null],
      "nama": [string],
      "alamat": [string | null],
      "telepon": [string | null]
    }
  }
}

6. Anda bisa mengecek token tersebut, untuk mengetahui atas kepemilikan user siapa, berikut caranya

// REST API menggunakan AJAX jQuery
$.ajax({
    url: "https://api.uinmadura.ac.id/api/auth/token",
    headers: {
        "Auth-token": YOUR_TOKEN,
        "Auth-api-key": YOUR_API_KEY
    },
    dataType: "json",
    success: function(response) {
        // response berupa informasi kepemilikan token tersebut
    }
});


// atau langsung embed dengan parameter URL
https://api.iainmadura.ac.id/api/auth/token?token=YOUR_TOKEN&key=YOUR_API_KEY
responnya berupa JSON
{
  "ip": [string],
  "created_at": [string],
  "expires_at": [string],
  "token": [string],
  "user": {
    "email": [string | null],
    "level": [1 | 2], // 1 dosen karyawan, 2 mahasiswa
    "kode": [string],
    "aplikasi": [array name aplication],
    "profil": {
      "avatar": [string | null],
      "nama": [string],
      "alamat": [string | null],
      "telepon": [string | null]
    }
  }
}

7. Untuk menghapus / menonaktifkan token, silahkan lakukan logout dengan cara sebagai berikut

// REST API menggunakan AJAX jQuery
$.ajax({
    url: "https://api.uinmadura.ac.id/api/auth/logout",
    headers: {
        "Auth-token": YOUR_TOKEN,
        "Auth-api-key": YOUR_API_KEY
    },
    dataType: "json",
    success: function(response) {
        // response berupa informasi kepemilikan token tersebut
    }
});

// atau langsung embed dengan parameter URL
"https://api.uinmadura.ac.id/api/auth/logout?token=YOUR_TOKEN&key=YOUR_API_KEY"
