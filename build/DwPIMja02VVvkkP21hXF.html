Pengenalan Awal

FirestoreService adalah sebuah wrapper utilitas untuk Firebase Firestore dan Firebase Storage di Flutter. Layanan ini dirancang untuk menyederhanakan operasi CRUD, manajemen file, dan real-time listening dengan sintaks yang lebih ringkas dan terpusat.

Konfigurasi Filter (WhereClause)

WhereClause

Gunakan class WhereClause untuk melakukan filtering pada query. Class ini mendukung seluruh operator standar Firestore.
Operator yang Tersedia:
  • ==, !=
  • <, <=, >, >=
  • array-contains, array-contains-any
  • in, not-in
Contoh Penggunaan:
List<WhereClause> filters = [
  WhereClause(field: 'status', value: 'active'),
  WhereClause(field: 'age', operator: WhereClause.greaterThan, value: 18),
];

Manajemen Koleksi (Read Operations)

A. Mengambil Data Sekali (Once)

Mengambil seluruh dokumen dalam koleksi berdasarkan filter tertentu.
final snapshot = await FirestoreService.getCollectOnce(
  'products',
  where: [WhereClause(field: 'category', value: 'electronics')],
  orderBy: 'createdAt',
  descending: true,
  limit: 10,
);

Mendengarkan Data Realtime (Stream)

Mendapatkan aliran data (stream) yang akan diperbarui secara otomatis saat ada perubahan di database.
StreamBuilder<QuerySnapshot>(
  stream: FirestoreService.getCollect('chats', orderBy: 'timestamp'),
  builder: (context, snapshot) {
    // Implementasi UI
  },
);

Operasi Dokumen Tunggal

A. Mengambil Satu Dokumen (Once)

Mengambil dokumen pertama yang ditemukan atau berdasarkan ID spesifik.
Map<String, dynamic>? userData = await FirestoreService.getFirstOnce(
  'users',
  idPrimary: 'user_123',
);

B. Realtime Single Document (Stream)

Mendengarkan perubahan pada satu dokumen secara spesifik.
FirestoreService.streamFirst(
  'settings',
  where: [WhereClause(field: 'type', value: 'app_config')],
).listen((data) {
  print(data);
});

Manipulasi Data (Write Operations)

A. Insert Data

Menambahkan dokumen baru. Jika id tidak diisi, Firestore akan membuat Auto-ID.
await FirestoreService.insert(
  'logs',
  {'action': 'login', 'time': DateTime.now()},
);

B. Update & Insert (Upsert)

Logika cerdas yang akan memperbarui dokumen jika ditemukan (berdasarkan ID atau filter), atau membuat dokumen baru jika tidak ada.
await FirestoreService.updateAndInsert(
  'inventory',
  {'stock': 50},
  where: [WhereClause(field: 'code', value: 'BRG001')],
);

C. Update & Delete

Melakukan pembaruan atau penghapusan data secara spesifik.
// Update
await FirestoreService.update('users', {'name': 'John'}, idPrimary: 'uid_01');

// Delete
await FirestoreService.delete('posts', idPrimary: 'post_88');

Firebase Storage (File Management)

Layanan ini mendukung pengelolaan file menggunakan Uint8List (byte data).
FiturDeskripsi
uploadFileMengunggah file baru ke folder tertentu.
replaceFileMenghapus file lama dengan nama yang sama dan mengunggah yang baru.
removeFileMenghapus file dari storage berdasarkan nama file.
Contoh Upload:
String? downloadUrl = await FirestoreService.uploadFile(
  myFileBytes,
  'profile_picture.jpg',
  folder: 'users/avatars',
);

Referensi Dokumen

Jika Anda hanya membutuhkan DocumentReference untuk keperluan relasi antar dokumen atau transaksi.
DocumentReference? ref = await FirestoreService.getReference(
  'categories',
  where: [WhereClause(field: 'name', value: 'Food')],
);
Contoh Implementasi Lengkap
Berikut adalah contoh sederhana penggunaan dalam fungsi asinkron:
void syncData() async {
  try {
    // 1. Cek data lama
    Map<String, dynamic>? existing = await FirestoreService.getFirstOnce(
      'profile',
      idPrimary: 'user_01',
    );

    // 2. Update atau Insert data baru
    await FirestoreService.updateAndInsert(
      'profile',
      {
        'name': 'Gemini User',
        'lastUpdate': FieldValue.serverTimestamp(),
      },
      idPrimary: 'user_01',
    );

    // 3. Upload file pendukung
    String? url = await FirestoreService.uploadFile(
      imageBytes,
      'avatar_user_01.png',
      folder: 'images',
    );

    print('Sync Berhasil: $url');
  } catch (e) {
    print('Terjadi kesalahan: $e');
  }
}

Pengiriman Data (Emit)

A. Mengirim Data Biasa (send)

Mengirim data tanpa menunggu balasan. Jika socket terputus, data akan masuk antrean (queue) dan dikirim otomatis saat tersambung kembali.
await SocketHelper.send('user:update-profile', {
  'name': 'Affan',
  'bio': 'Software Developer'
});

B. Mengirim File (sendChunk)

Gunakan ini untuk mengirim File  yang sangat besar. Sistem akan memecah data menjadi bagian-bagian kecil agar tidak membebani memori/bandwidth.
await SocketHelper.sendChunk(
  'upload:avatar',
  myFile, // Bisa berupa File atau Uint8List
  onProgress: (percent) {
    print('Progres: $percent%');
  },
  onData: (response) {
    print('Data diterima: $response');
  },
  onError: (err) {
    print('Gagal kirim: $err');
  },
);
Namu di server harus menerima dengan teknik khusus agar mendukung sendChunk

Teknik untuk menerima data dari sendChunk di server NodeJS

const { Chunk } = require('./chunk');

io.on("connection", (socket) => {
  const fileReceiver = new Chunk("upload-document", socket, {
    saveDir: "./uploads/documents",
    maxSize: 20 * 1024 * 1024, // Batasi 20MB
  });

  fileReceiver.done((result) => {
    if (result.status) {
      console.log("File berhasil dirakit di:", result.data);
      // result.data berisi path file utuh (misal: ./uploads/documents/transferId.bin)
    }
  });
});

C. Mengirim Data Besar (sendChunk)

Gunakan ini untuk mengirim objek JSON yang sangat besar. Sistem akan memecah data menjadi bagian-bagian kecil agar tidak membebani memori/bandwidth.
Future<void> sendLargeData(Map<String, dynamic> bigMap) async {
  await SocketHelper.sendChunk(
    'sync-offline-data',
    bigMap, // Kirim Map/List besar
    onProgress: (percent) => print("Syncing: $percent%"),
    onData: (response) {
      print("Data diproses server: $response");
    }
  );
}
Namu di server harus menerima dengan teknik khusus agar mendukung sendChunk

Teknik untuk menerima data dari sendChunk di server NodeJS

const { Chunk } = require('./chunk');

io.on("connection", (socket) => {
  const dataReceiver = new Chunk("sync-offline-data", socket, {
    onComplete: async (result) => {
      if (result.status && !result.isFile) {
        const bigData = result.data; // Sudah otomatis jadi Object JSON
        console.log("Menerima data besar sejumlah:", Object.keys(bigData).length);
        
        // Kamu bisa proses ke database disini
        return { status: true, message: "Data berhasil disinkronisasi" };
      }
    }
  });
});

D. Skenario Return Data

Berikut adalah penjelasan data apa yang kamu dapatkan saat melakukan await:
1. Jika onComplete di Node.js mengembalikan Data (Custom)
Jika di Node.js kamu menggunakan onComplete dan mengembalikan sebuah Object/String, maka itulah yang akan diterima oleh await di Flutter.
Node.js (Server):
const fileReceiver = new Chunk("upload", socket, {
  onComplete: (result) => {
    // Apapun yang di-return di sini akan dikirim ke Flutter
    return { 
      status: "success", 
      fileUrl: "https://cdn.com/file.png",
      id: 101 
    };
  }
});

Flutter Client:

final response = await SocketHelper.sendChunk('upload', file);
print(response['fileUrl']); // Output: https://cdn.com/file.png
2. Jika Node.js TIDAK menggunakan onComplete
Jika kamu tidak mendefinisikan onComplete di Node.js, maka class Chunk akan menggunakan nilai default messageDone.
Node.js (Server):
const fileReceiver = new Chunk("upload", socket, {
  messageDone: "Mantap, file sudah masuk!"
});

Flutter Client:

final response = await SocketHelper.sendChunk('upload', file);
print(response); // Output: "Mantap, file sudah masuk!"

Analisis Alur Completer

Di kodingan Flutter-mu, completer akan selesai (complete) dalam dua kondisi utama:
  1. Normal (Non-Custom): Begitu semua chunk terkirim, client langsung me-resolve dengan "Done".
  2. Custom Response (returnCustom): Client menunggu event complete dari server (yang dikirim oleh class Chunk Node.js setelah file selesai dirakit).

Kapan await ini Error?

await akan melempar Exception (catch error) jika di sisi Flutter terjadi:
  • Reject: Jika server mengirim sinyal reject.
  • Error: Jika terjadi max_size_exceeded atau timeout di sisi server.
  • Mismatched: Jika ukuran data yang dirakit tidak sama dengan total yang dikirim.

Mengambil & Mendengarkan Data

A. Mengambil Data Sekali (getOnce)

Cocok untuk pengganti REST API (Request-Response). Fungsi ini mengembalikan Future.
final response = await SocketHelper.getOnce('form:detail', data: {'id': '123'});
print('Data Form: $response');

B. Mendengarkan Secara Reaktif (get)

Mengirim permintaan dan memantau perubahan data secara terus-menerus.
final watcher = SocketHelper.get(
  'form:index',
  data: {'page': 1},
  onWatch: (newData) {
    setState(() => dataList = newData);
  },
);

// Untuk mematikan listener:
watcher.off();

C. Mendengarkan Saja (on)

Hanya mendengarkan event yang dikirim dari server tanpa melakukan emit permintaan di awal.
final watcher = SocketHelper.on('notification:receive', onWatch: (data) {
  print('Notifikasi baru: $data');
});

Penggunaan Massal (SocketBatchWatcher)

Gunakan ini di dalam initState sebuah halaman untuk mengelola banyak listener sekaligus dan mematikannya dengan satu perintah di dispose.

A. Menggunakan pemanggilan secara massal dan dapat di dispose juga secara massal

class MyPage extends StatefulWidget { ... }

class _MyPageState extends State<MyPage> {
  SocketBatchWatcher? _batch;

  @override
  void initState() {
    super.initState();
    _batch = SocketBatchWatcher.batchWatcher(
      emit: {
        'form:index': {'page': 1},
        'user:status': null,
      },
      listener: {
        'form:index': (data) => print('Data Form: $data'),
        'user:status': (data) => print('Status User: $data'),
        'global:alert': (data) => print('Pesan Server: $data'), // listener tanpa emit
      },
    );
  }

  @override
  void dispose() {
    _batch?.off(); // Mematikan semua listener di atas sekaligus
    super.dispose();
  }
}

Pemantauan Status Koneksi

Kamu bisa menampilkan indikator koneksi (misal: icon hijau/merah) secara real-time di UI.

A. Menggunakan ValueListenableBuilder

ValueListenableBuilder<bool>(
  valueListenable: SocketHelper.socketStatus,
  builder: (context, isOnline, child) {
    return Icon(
      Icons.circle,
      color: isOnline ? Colors.green : Colors.red,
    );
  },
);

B. Menggunakan Stream

SocketHelper.statusStream.listen((isOnline) {
  if (!isOnline) SnackbarHelper.show('Anda sedang offline');
});
