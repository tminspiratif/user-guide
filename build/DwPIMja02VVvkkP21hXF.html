Firestore Services

1. Inisialisasi Class

Simpan file ini di lib/core/services/firestore_service.dart.
import 'package:cloud_firestore/cloud_firestore.dart';

class FirestoreService {
  final FirebaseFirestore _db = FirebaseFirestore.instance;

  // Singleton Pattern (Opsi agar hemat memori)
  static final FirestoreService _instance = FirestoreService._internal();
  factory FirestoreService() => _instance;
  FirestoreService._internal();
}

2. Operasi Dasar (CRUD)

A. Set/Update Data (Write)

Gunakan ini untuk menyimpan data user atau setting yang memiliki ID unik.
Future<void> setData(String path, Map<String, dynamic> data) async {
  await _db.doc(path).set(data, SetOptions(merge: true));
}

B. Add Data (Auto-ID)

Gunakan ini untuk transaksi, pesanan, atau log yang ID-nya dibuat otomatis oleh Firebase.
Future<void> addData(String collectionPath, Map<String, dynamic> data) async {
  await _db.collection(collectionPath).add(data);
}

C. Get Document (Read Once)

Gunakan ini untuk mengambil profil user atau satu data spesifik.
Future<DocumentSnapshot> getDoc(String path) async {
  return await _db.doc(path).get();
}

C. Get Document (Read Once)

Gunakan ini untuk mengambil profil user atau satu data spesifik.
Future<DocumentSnapshot> getDoc(String path) async {
  return await _db.doc(path).get();
}

D. Delete Data

Future<void> deleteDoc(String path) async {
  await _db.doc(path).delete();
}

3. Operasi Real-time (Stream)

Sangat penting untuk aplikasi project agar data meja atau pesanan sinkron otomatis.

A. Stream Collection (Daftar Data)

Stream<QuerySnapshot> streamCol(String path, {Query Function(Query)? query}) {
  if (query != null) {
    return query(_db.collection(path)).snapshots();
  }
  return _db.collection(path).snapshots();
}

B. Stream Document (Data Tunggal)

Stream<DocumentSnapshot> streamDoc(String path) {
  return _db.doc(path).snapshots();
}

Inisialisasi & Koneksi

Lakukan koneksi sekali saja (biasanya di main.dart atau layar inisialisasi).

await SocketHelper.connect(
  'https://ws.uinmadura.ac.id',
  token: 'JWT_TOKEN_KAMU', // Opsional
  onStatus: (isConnected) {
    print('Status Koneksi: $isConnected');
  },
);

// Aktifkan log untuk debugging
SocketHelper.enableDebug(true);

Pengiriman Data (Emit)

A. Mengirim Data Biasa (send)

Mengirim data tanpa menunggu balasan. Jika socket terputus, data akan masuk antrean (queue) dan dikirim otomatis saat tersambung kembali.
await SocketHelper.send('user:update-profile', {
  'name': 'Affan',
  'bio': 'Software Developer'
});

B. Mengirim File/Data Besar (sendChunk)

Gunakan ini untuk mengirim File atau objek JSON yang sangat besar. Sistem akan memecah data menjadi bagian-bagian kecil agar tidak membebani memori/bandwidth.
await SocketHelper.sendChunk(
  'upload:avatar',
  myFile, // Bisa berupa File atau Uint8List
  onProgress: (percent) {
    print('Progres: $percent%');
  },
  onData: (response) {
    print('Data diterima: $response');
  },
  onError: (err) {
    print('Gagal kirim: $err');
  },
);

Mengambil & Mendengarkan Data

A. Mengambil Data Sekali (getOnce)

Cocok untuk pengganti REST API (Request-Response). Fungsi ini mengembalikan Future.
final response = await SocketHelper.getOnce('form:detail', data: {'id': '123'});
print('Data Form: $response');

B. Mendengarkan Secara Reaktif (get)

Mengirim permintaan dan memantau perubahan data secara terus-menerus.
final watcher = SocketHelper.get(
  'form:index',
  data: {'page': 1},
  onWatch: (newData) {
    setState(() => dataList = newData);
  },
);

// Untuk mematikan listener:
watcher.off();

C. Mendengarkan Saja (on)

Hanya mendengarkan event yang dikirim dari server tanpa melakukan emit permintaan di awal.
final watcher = SocketHelper.on('notification:receive', onWatch: (data) {
  print('Notifikasi baru: $data');
});

Penggunaan Massal (SocketBatchWatcher)

Gunakan ini di dalam initState sebuah halaman untuk mengelola banyak listener sekaligus dan mematikannya dengan satu perintah di dispose.

A. Menggunakan pemanggilan secara massal dan dapat di dispose juga secara massal

class MyPage extends StatefulWidget { ... }

class _MyPageState extends State<MyPage> {
  SocketBatchWatcher? _batch;

  @override
  void initState() {
    super.initState();
    _batch = SocketBatchWatcher.batchWatcher(
      emit: {
        'form:index': {'page': 1},
        'user:status': null,
      },
      listener: {
        'form:index': (data) => print('Data Form: $data'),
        'user:status': (data) => print('Status User: $data'),
        'global:alert': (data) => print('Pesan Server: $data'), // listener tanpa emit
      },
    );
  }

  @override
  void dispose() {
    _batch?.off(); // Mematikan semua listener di atas sekaligus
    super.dispose();
  }
}

Pemantauan Status Koneksi

Kamu bisa menampilkan indikator koneksi (misal: icon hijau/merah) secara real-time di UI.

A. Menggunakan ValueListenableBuilder

ValueListenableBuilder<bool>(
  valueListenable: SocketHelper.socketStatus,
  builder: (context, isOnline, child) {
    return Icon(
      Icons.circle,
      color: isOnline ? Colors.green : Colors.red,
    );
  },
);

B. Menggunakan Stream

SocketHelper.statusStream.listen((isOnline) {
  if (!isOnline) SnackbarHelper.show('Anda sedang offline');
});
