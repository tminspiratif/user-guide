INPUT NILAI

Generate Token

Sebelum melakukan penginputan nilai maka dipastikan untuk memahami generate token

1. Klik tombol menu Nilai pada daftar menu sistem yang berada di sebelah kiri

Silahkan menuju ke menu NILAI di menu sebelah kiri (Sidebar)

2. Lalu submenu Generate Token Input Nilai

3. Generate Token Aksi

Silahkan ikuti langkah-langkah dibawah ini
Sekarang anda dapat melakukan generate token dengan 2 cara:, 
  1. dapat dengan cara menandai secara massal (merah)
  2. dapat dengan cara menandai perorangan (biru)
sedangkan yand ditandai dengan kotak hijau merupakan aksi apabila sudah ditandai (yang mana yang akan digenerate tokennya)
dan yang warna kuning merupakan token yang dapat digunakan untuk penginputan nilai
